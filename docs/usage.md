## 1. 按键写法与界面概念

### 1.1 如何读快捷键

| 手册写法 | 实际按法 |
| --- | --- |
| `Ctrl+s` | 按住 Ctrl，再按 s |
| `Shift+h` 或 `H` | 按住 Shift，再按 h |
| `空格 f p` | 依次按空格、f、p，不需要同时按 |
| `空格 q S` | 依次按空格、q、Shift+s |
| `Alt+←/→` | Alt+左方向键，或 Alt+右方向键 |
| `:WorkspaceSave` | 普通模式按冒号，输入 WorkspaceSave，再按 Enter |
| `3j` | 先按数字 3，再按 j |

快捷键区分大小写。本文中的 `空格` 是引导键，也就是配置中的 `<leader>`。

除特别注明外，所有 `空格 …` 快捷键都在**普通模式**下使用。若你正在输入文字，先按 Esc。若正在终端里输入命令，先按 `Ctrl+\`，松开后再按 `Ctrl+n`，或使用文中直接支持终端模式的按键。

### 1.2 界面上各部分是什么

| 区域 / 名称 | 作用 |
| --- | --- |
| 启动页 | 选择最近项目、最近文件、搜索和常用操作 |
| 左侧文件树 | 浏览磁盘中的项目目录和文件 |
| 编辑区 | 修改当前文件 |
| 编辑区内部文件标签 | 显示已打开的文件，即文件缓冲区 |
| 右侧代码缩略图 | 查看代码整体结构、位置与标记 |
| 底部终端面板 | 运行 shell、服务、构建或其他命令 |
| 终端内部标签 | 切换独立 shell 进程 |
| 底部状态栏 | 查看模式、Git 分支、文件、诊断、文件类型、行列等 |
| 项目工作区 | 一组项目目录、文件、分屏、视图与终端布局记录 |

当前区域使用较亮的边框。当前文件或终端标签使用实色背景和 `▎` 标记。文件标签中的圆点表示内容有未保存修改。

**文件、缓冲区、窗口不是同一回事：**

- 文件：磁盘上的实际内容。
- 缓冲区：Neovim 已打开的内容，修改后未必已经写入磁盘。
- 窗口：显示某个缓冲区的区域。同一文件可以显示在两个分屏中。
- 项目工作区标签页：保存一组窗口；不等同于编辑区顶部的文件标签。

### 1.3 不记得快捷键时怎么办

1. 先按 Esc 返回普通模式。
2. 按一下空格，等待中文快捷键提示。
3. 按提示中的下一层按键，继续查看。
4. 按 Esc 取消。

也可按 **F1** 或连续按两次空格，打开中文工作台，通过菜单选择项目、文件、任务、调试、Git、备份等操作。

## 2. 第一次使用：完成一次编辑

### 2.1 打开一个项目

在 PowerShell 中执行，目录换成自己的项目：

```powershell
cd 'C:\My\code\my-project'
nvim
```

如果已经进入 Neovim，按 `空格 f p` 搜索最近项目。没有历史记录的新目录，直接从终端进入该目录再启动即可。

也可以直接打开文件：

```powershell
nvim .\README.md
```

### 2.2 查找并修改文件

1. 按 `Ctrl+p` 打开文件搜索。
2. 输入文件名的一部分，例如 `README`。
3. 用上下方向键选择结果，按 Enter 打开。
4. 按 `i` 进入输入模式。
5. 输入一行内容。
6. 按 Esc 回到普通模式。
7. 按 `Ctrl+s` 保存。

### 2.3 再打开一个文件

再次按 `Ctrl+p`，选择第二个文件。两个文件都会保留为缓冲区：

- 鼠标点击编辑区顶部标签切换。
- `Shift+h` / `Shift+l` 切换到上一个 / 下一个缓冲区。
- `空格 b d` 关闭当前文件，不删除磁盘文件。

### 2.4 打开终端后回到编辑器

1. 普通模式按 `空格 t` 新建终端。
2. 在终端输入 `git status` 并回车。
3. 按 `Ctrl+k` 返回上方编辑区，或直接点击代码区。
4. 按 F7 隐藏终端；再按 F7 重新显示。

### 2.5 结束本次编辑

1. 保存需要保留的文件。
2. 普通模式输入 `:Exit` 并回车。
3. 选择“保存所有文件并退出”或“不保存所有文件并退出”。
4. 暂时不退出，按 Esc 取消。

不要把“不保存退出”理解为“下次工作区会找回全部改动”：工作区不保存未写盘的文本草稿。

## 3. 模式切换与命令输入

### 3.1 普通模式

普通模式负责移动、删除、复制、搜索和执行快捷键。按 Esc 一般可以回到这个模式。左下状态栏通常显示“普通”。

此时输入 `j` 会移动光标，而不是输入字母 j。需要打字时先进入输入模式。

### 3.2 输入模式

| 按键，先在普通模式使用 | 效果 |
| --- | --- |
| `i` | 在当前字符前开始输入 |
| `a` | 在当前字符后开始输入 |
| `I` | 在当前行第一个非空白字符前输入 |
| `A` | 在当前行末尾输入 |
| `o` | 在下方新建一行并开始输入 |
| `O` | 在上方新建一行并开始输入 |
| Esc | 结束输入，回到普通模式 |

这份配置还保留了个人映射：输入模式或选择模式连续按 `pp` 会返回普通模式。输入 `apple` 等带连续 `pp` 的文本时可能触发它。若不需要，请在 `lua/config/keymaps.lua` 删除该映射后重启。

### 3.3 可视选择模式

| 按键 | 用途 |
| --- | --- |
| `v` | 按字符选择 |
| `V` | 按整行选择 |
| 普通模式 `Ctrl+v` | 按矩形块选择 |
| Esc | 取消选择 |

注意：普通模式的 `Ctrl+v` 是块选择；**输入模式的 `Ctrl+v` 才是 Windows 剪贴板粘贴**。

### 3.4 命令行模式

普通模式按 `:` 后输入命令。常用命令的候选项会附带中文说明，命令名仍使用英文。

- 上下方向键或 `Ctrl+n / Ctrl+p`：选择候选。
- Enter：确认命令。
- Esc：取消。
- 输入 `:help`：打开 Neovim 帮助。
- 输入 `:help :write`：查看某条命令的帮助。

在 Neovim 命令行中输入 Windows 路径时，建议使用 `/`，例如 `:edit C:/My/code/demo/Main.java`。路径有空格时使用文件选择器，或用 `:edit` 的路径补全，避免手工遗漏转义。

## 4. 移动光标与定位代码

所有下列移动都先在普通模式使用。鼠标点击和方向键也可以移动光标。

### 4.1 基础移动

| 按键 | 动作 |
| --- | --- |
| `h / j / k / l` | 左 / 下 / 上 / 右 |
| `5j` / `5k` | 向下 / 向上移动 5 行 |
| `0` | 当前行开头，包括缩进空白 |
| `^` | 当前行第一个非空白字符 |
| `$` | 当前行末尾 |
| `gg` | 文件第一行 |
| `G` | 文件最后一行 |
| `120G` | 第 120 行 |
| `:120` 后 Enter | 跳到第 120 行 |
| `%` | 在匹配的括号之间跳转，依赖当前语法上下文 |

### 4.2 按词和子单词移动

这份配置使用 nvim-spider：`w / e / b` 会识别驼峰或下划线中的子单词。例如 `userAccountId` 可以分段移动。

- `w`：下一个子单词。
- `e`：当前 / 下一个子单词末尾。
- `b`：上一个子单词。
- `W / E / B`：以空白分隔的大范围 WORD 移动。

### 4.3 翻页与调整视图

| 按键 | 动作 |
| --- | --- |
| `Ctrl+d` / `Ctrl+u` | 下 / 上滚动约半屏 |
| `Ctrl+f` / `Ctrl+b` | 下 / 上翻页 |
| `zz` | 将当前光标行置于屏幕中间附近 |
| `zt` / `zb` | 将当前行移到视图上方 / 下方 |
| `zh / zl` | 向左 / 向右水平滚动 |

默认不自动换行。长行超出右侧时，可以移动光标或水平滚动，不代表内容丢失。

- `:set wrap`：临时显示自动换行。
- `:set nowrap`：恢复不自动换行。

### 4.4 跳转后返回

- `F12`：通过语言服务跳到定义。
- `Shift+F12`：查看引用。
- 编辑区 `Alt+←` 或 `Ctrl+o`：回到前一个跳转位置。
- 编辑区 `Alt+→` 或 `Ctrl+i`：向前。

终端中 `Alt+←/→` 的含义是切换终端标签，与编辑区不同。

## 5. 选择、复制、剪切与粘贴

### 5.1 复制一段代码到 Windows

1. 普通模式将光标移到开始位置。
2. 按 `v` 进入字符选择，或者按 `V` 选择整行。
3. 移动光标扩大选择范围。
4. 按 `y` 或 `Ctrl+c` 复制。
5. 切换到其他 Windows 程序粘贴。

### 5.2 从 Windows 粘贴到 Neovim

先在其他程序复制：

- Neovim 普通模式按 `p`，在光标后粘贴。
- 按 `P`，在光标前粘贴。
- 输入模式按 `Ctrl+v`，在当前输入位置粘贴。

剪贴板异常时执行 `:checkhealth vim.provider`，确认 Windows provider 可用。

### 5.3 常用复制与剪切

| 按键 | 效果 |
| --- | --- |
| `yy` | 复制当前行 |
| `3yy` | 复制当前行开始的 3 行 |
| 选择后 `y` | 复制选中的内容 |
| `dd` | 删除 / 剪切当前行 |
| `3dd` | 删除 / 剪切当前行开始的 3 行 |
| 选择后 `d` | 删除 / 剪切选中内容 |
| `p` | 粘贴最近复制 / 删除的内容 |

本配置将默认寄存器连接到 Windows 剪贴板。因此，普通的删除操作也可能覆盖系统剪贴板内容。

如果只想删除，不改变剪贴板，可以使用黑洞寄存器：`"_dd` 删除当前行；选择后 `"_d` 删除所选内容。

## 6. 插入、删除、修改、缩进与撤销

### 6.1 常用修改

| 按键 | 效果 |
| --- | --- |
| `x` | 删除当前字符 |
| `D` | 删除光标到行尾 |
| `C` | 修改光标到行尾，然后进入输入模式 |
| `cc` | 修改整行，然后进入输入模式 |
| `r` 后接一个字符 | 替换光标下的单个字符 |
| `J` | 合并当前行和下一行 |
| `.` | 重复上一次可重复的修改 |

例如：按 `A` 在行尾添加分号，Esc 返回；移动到另一行按 `.`，可重复该修改。复杂插件操作不一定支持点号重复。

### 6.2 使用文本对象修改

文本对象描述“引号里面”“括号里面”等范围，不必先精确选择全部字符。

| 示例 | 含义 |
| --- | --- |
| `ci"` | 修改双引号内部内容 |
| `yi"` | 复制双引号内部内容 |
| `di(` | 删除圆括号内部内容，保留括号 |
| `da{` | 删除花括号及其包围的内容 |
| `vi(` | 选择圆括号内部内容 |
| `diI` | 删除当前缩进块内部，最后一个字符是大写 I |
| `vaI` | 选择整个缩进块，最后一个字符是大写 I |

操作前确认光标处在相应结构中；注释、字符串或没有语法支持的位置可能与预期不同。

### 6.3 缩进与格式化

- 普通模式 `>>`：增加当前行缩进。
- 普通模式 `<<`：减少当前行缩进。
- 选择多行后 `>` / `<`：调整选择范围的缩进。
- `空格 c f`：调用配置的格式化工具。

格式化取决于对应工具是否安装，以及项目自己的格式规则。手工缩进与代码格式化是两种操作。

### 6.4 撤销与重做

- `u`：撤销上一次修改。
- `Ctrl+r`：重做。
- `空格 s u`：打开 / 关闭撤销历史树，查看不同修改分支。

如果刚刚操作错了，优先按 Esc，再按 `u`，不要立刻关闭文件或重启。

### 6.5 单行 / 多行结构切换

在支持的参数列表、数组、对象等结构中，按 `空格 c j`，TreeSJ 会尝试切换单行 / 多行。此功能依赖对应 Tree-sitter 解析器和插件支持的结构，并非任意文本都能转换。

## 7. 文件内搜索与替换

### 7.1 搜索当前文件

1. 普通模式按 `/`。
2. 输入关键词，Enter 确认。
3. `n` 跳到下一个匹配；`N` 跳到上一个匹配。
4. 按 Esc 不会删除文本。

`?关键词` 向反方向搜索。输入 `:nohlsearch` 可清除搜索高亮，之后再次搜索还会恢复匹配显示。

### 7.2 带确认地替换

```vim
:%s/oldName/newName/gc
```

含义：在整个当前文件中，将 `oldName` 替换为 `newName`，每次替换前询问。

- `y`：替换当前匹配。
- `n`：跳过当前匹配。
- `q`：结束本次替换。
- `a`：替换剩余所有匹配。

`g` 表示一行内所有匹配；`c` 表示逐个确认。搜索部分是 Vim 正则表达式，不是始终按普通文本匹配。路径中的 `/` 需要转义，或者更换分隔符，例如 `:%s#old/path#new/path#gc`。

### 7.3 重命名代码符号用什么

变量、方法、类的重命名优先使用 **F2**，通过语言服务理解引用关系。文本替换只匹配文字，不理解代码作用域，不能当成语义重命名。

## 8. 项目、文件树与项目搜索

### 8.1 选择最近项目

- 启动页按 `p`。
- 编辑过程中按 `空格 f p`。
- 输入项目名或目录的一部分，选择后 Enter。

同名项目通过附带目录区分。没有历史的新项目，可以先从终端进入目录并运行 Neovim。配置会根据 Git、构建文件或其他项目标记记录目录。

切换项目会保存工作区记录；若该项目已在当前进程打开，会复用已有工作区标签页。重新进入带有工作区记录的项目时会尝试恢复布局和文件。

### 8.2 使用文件树

按 `空格 e` 打开 / 收起文件树：

1. 用上下方向键或 `j/k` 选择条目。
2. 对目录按 Enter 展开 / 收起；对文件按 Enter 打开。
3. 也可以用鼠标点击条目，再按 Enter 确认。
4. 按 `/` 显示搜索输入框并筛选文件树。
5. Esc 结束筛选；离开筛选框也会清除并收起输入框。

文件树顶部显示项目名称及路径。编辑区文件标签只表示已经打开的文件，文件树则表示磁盘目录，两者列表不必一致。

文件树获得焦点后，还可使用这些操作：

| 按键 | 操作 |
| --- | --- |
| `l` / Enter | 打开文件或确认目录条目 |
| `h` | 收起目录 |
| Backspace | 进入上级目录 |
| `a` | 新建文件 / 目录，按提示输入名称 |
| `r` | 重命名选中条目 |
| `d` | 删除选中条目，按确认提示操作 |
| `H` | 切换隐藏文件显示 |
| `I` | 切换 Git 忽略项显示 |
| `u` | 刷新文件树 |
| `Z` | 收起所有目录 |

文件树里的 `d` 操作磁盘文件；编辑区的 `空格 b d` 只关闭缓冲区，两者不同。文件改名、移动后如语言服务引用未同步，需要检查代码和项目构建结果。

### 8.3 在 Windows 文件资源管理器中显示

1. 让文件树获得焦点。
2. 选择文件或目录。
3. 依次按 `g`、`Shift+e`，也就是 `g E`。

选中文件时，在 Windows 文件资源管理器中定位该文件；选中目录时打开目录。文件树右键菜单也提供对应入口。

### 8.4 查找文件名

按 `Ctrl+p` 或 `空格 f f`，输入文件名或路径片段，例如：

```text
AdminController
src commands
README
```

选择结果后 Enter 打开；Esc 取消。该入口按项目搜索，不是在当前文件正文里查找。

### 8.5 搜索整个项目的文本

1. 按 `空格 /`。
2. 输入关键字，例如 `registerDevice`。
3. 查看匹配文件、行号和预览。
4. 选择一个结果，Enter 跳转。

搜索依赖 `rg`。文件可能受忽略规则影响；没有结果时先确认 `:pwd` 和项目根目录。

### 8.6 新建文件

可以从启动页按 `n` 打开未命名缓冲区，或输入：

```vim
:edit C:/My/code/demo/NewFile.java
```

输入内容后执行 `:write`。目录不存在时，需要先建立目录。未命名文件保存时可指定路径：`:write C:/My/code/demo/notes.txt`。

## 9. 文件标签与缓冲区管理

### 9.1 切换文件

- 点击编辑区内部标签。
- `Shift+h`：上一个缓冲区。
- `Shift+l`：下一个缓冲区。
- `[b` / `]b`：上一个 / 下一个缓冲区。
- 用文件搜索重新打开同一路径，会使用已存在的缓冲区。

标签栏空间有限，打开很多文件时不保证全部文件名同时显示。仍可通过快捷键切换，或者按 `Ctrl+p` 选择目标文件。

### 9.2 关闭当前文件而保留编辑区

推荐 `空格 b d`。也可以在交互命令行中输入 `:bd` 或 `:BufferClose`。

- 还有文件：切换到最近使用的其他文件，保留编辑窗口。
- 有修改：弹出保存、放弃或取消选项。
- 最后一个文件：返回启动页。
- 不会删除磁盘上的原文件。

需要明确放弃当前修改时使用 `:bd!`。不要把 `:q` 当成关闭文件标签，`:q` 是关闭当前窗口。

交互输入的独立 `:bd` / `:bdelete` 会重定向到本配置的关闭逻辑。脚本中的原生命令、带复杂参数的原生命令不保证经过该重定向；关闭指定缓冲区可用 `:BufferClose 缓冲区编号`。

### 9.3 查看缓冲区列表

输入 `:ls` 查看缓冲区编号、文件名和标记。可以用 `:buffer 3` 切换到编号 3 的缓冲区，具体编号以列表为准。

这里的“缓冲区编号”不同于终端标签显示的编号。

## 10. 分屏、鼠标与区域切换

### 10.1 用鼠标操作

- 点击代码区，移动光标并聚焦。
- 点击文件树，选择目录或文件条目。
- 点击终端，向当前 shell 输入。
- 点击文件标签或终端标签，切换对应内容。
- 点击缩略图，定位代码。

标签栏点击不用于选中文字。正文中的鼠标拖动仍可用于选择。终端程序若自行接管鼠标，其内部行为由程序决定。

### 10.2 使用键盘切换区域

| 按键 | 方向 |
| --- | --- |
| `Ctrl+h` | 左侧区域 |
| `Ctrl+j` | 下方区域 |
| `Ctrl+k` | 上方区域 |
| `Ctrl+l` | 右侧区域 |

这些按键在普通模式和终端模式中可用。代码输入模式先按 Esc；不要期待输入模式的 Ctrl+h 与普通模式完全相同。

典型布局中：编辑区 `Ctrl+h` 进入文件树，编辑区 `Ctrl+j` 进入底部终端，终端 `Ctrl+k` 返回代码区。没有对应方向的区域时，不会凭空创建窗口。

### 10.3 调整窗口大小

| 按键 | 当前区域的尺寸变化 |
| --- | --- |
| `Ctrl+↑` | 增高 2 行 |
| `Ctrl+↓` | 降低 2 行 |
| `Ctrl+←` | 变窄 2 列 |
| `Ctrl+→` | 变宽 2 列 |

终端的圆角内容窗口会映射到它的底部容器进行调整。调整受到其他窗口最小尺寸限制。

### 10.4 对照编辑两个文件

1. 打开第一个文件。
2. 输入 `:vsplit`，创建左右分屏。
3. 在当前分屏用 `Ctrl+p` 打开第二个文件。
4. 用 `Ctrl+h/l` 在左右代码窗口之间移动。
5. 用 `Ctrl+方向键` 调整宽度。

`:split` 创建上下分屏。若想关闭文件但保留布局，用 `空格 b d`；明确要关闭某个窗口时才用 `:close` 或 `:q`。自定义标签栏和底边属于辅助窗口，优先聚焦代码正文后再执行窗口命令。

## 11. 终端与终端标签

### 11.1 新建和切换

在普通模式按 `空格 t`，每次创建一个新 shell 标签，多个终端共用底部面板。

| 操作 | 入口 |
| --- | --- |
| 新建终端 | 普通模式 `空格 t` |
| 切换终端 | 点击内部标签 |
| 上一个 / 下一个终端 | 终端内 `Alt+← / Alt+→` |
| 查看所有终端 | 普通模式 `空格 T` |
| 隐藏 / 显示面板 | F7 |

终端数量没有固定上限，但每个 shell 都会占用系统资源。启动目录取决于新建时的当前工作目录。

### 11.2 输入模式与普通模式

终端输入状态下，字母、空格和回车通常发送给 shell。**直接按空格 t 不会新建终端，而是向 shell 输入文字。**

退出终端输入状态：

1. 按 `Ctrl+\`。
2. 松开后按 `Ctrl+n`。
3. 此时可以滚动查看内容或执行普通模式快捷键。
4. 按 `i` 继续输入 shell 命令。

Snacks 终端也支持双击 Esc 返回终端普通模式；若与终端程序按键冲突，使用上面的两步按法。

### 11.3 隐藏、切走、结束有什么区别

| 需求 | 使用 |
| --- | --- |
| 暂时不看终端，程序继续运行 | F7 隐藏 |
| 终端仍显示，只回到代码 | `Ctrl+k` 或点击代码区 |
| 切到另一个 shell | 点击终端标签或 `Alt+方向键` |
| 停止当前前台命令 | 按该程序支持的中断键，常见为 Ctrl+c |
| 退出当前 shell | 输入 `exit` 并 Enter |

F7 不会停止服务或构建。`exit` 是结束 shell，不是隐藏面板；前台程序尚在运行时，输入内容可能先被该程序接收。

### 11.4 推荐的两个终端用法

- 终端 1：运行开发服务，持续看日志。
- 终端 2：执行 `git status`、临时脚本或其他命令。

操作顺序：`空格 t` 创建终端 1 → 启动服务 → `Ctrl+k` 回代码 → Esc 确认普通模式 → `空格 t` 创建终端 2 → 点击标签来回切换。

### 11.5 看历史输出和复制

先退出终端输入状态，再用普通模式移动、选择和复制。按 `i` 回到命令输入。终端程序是否保存完整历史、是否采用备用屏幕，取决于程序本身；不能假定所有 TUI 的历史都能像普通文件一样滚动。

### 11.6 高度和颜色

调整终端高度后，新建和切换标签会沿用面板高度。默认 `cmd` 的提示符和 `dir` 可能是单色；只有实际输出 ANSI 颜色的命令才会呈现彩色。修改颜色环境后应新建终端，旧进程不会自动重新读取环境变量。

## 12. 工作区保存与恢复

### 12.1 保存的是什么

工作区按项目目录分别记录：

- 已打开的文件，包括暂时没有显示在分屏中的文件缓冲区。
- 分屏方向与尺寸比例。
- 当前文件、光标行列、滚动位置。
- 文件树是否打开及宽度。
- 终端标签数量、面板高度和显示状态。

不会保存数据库连接进程、服务进程、终端输出，也不会自动把未保存的源码写入磁盘。

### 12.2 手动保存和恢复

| 操作 | 快捷键 | 命令 |
| --- | --- | --- |
| 保存当前项目工作区 | `空格 q S` | `:WorkspaceSave` |
| 恢复当前项目工作区 | `空格 q s` | `:WorkspaceRestore` |

大小写不同：保存是大写 S，恢复是小写 s。

手动恢复会新建项目工作区标签页，保留当前窗口和缓冲区。连续恢复可能出现多个工作区标签页，不是把当前所有内容清空后覆盖。

### 12.3 自动保存和恢复

配置在离开项目标签页、切换项目、正常退出 Neovim 时自动保存工作区。从项目列表重新打开有记录的项目时，会尝试恢复；项目在当前进程已经打开时优先复用。

强制终止进程、系统断电或崩溃不保证触发正常退出保存。重要布局可在操作后手动保存一次。

### 12.4 正确的下班与次日恢复流程

**结束工作：**

1. 保存需要保留的文件，多个文件可执行 `:wall`。
2. 需要结束的服务，在对应终端手动停止。
3. 按 `空格 q S` 保存布局。
4. 执行 `:Exit` 退出。

**下次继续：**

1. 启动 Neovim。
2. 启动页按 `p` 选中项目。
3. 等待文件与布局恢复。
4. 在重建的终端中自行重新启动服务或构建。

同一次 Neovim 中恢复时会保留已存在的未保存缓冲区；重新启动后按磁盘内容读取文件。因此不能用“保存工作区”代替“保存文件”。已被移动或删除的文件会跳过。

工作区记录位于 `stdpath('state')/workspaces`，不写入项目仓库。

## 13. 补全、跳转、重命名与诊断

### 13.1 自动补全

打开项目源码后，等待语言服务启动。输入代码时，补全菜单会显示候选。

当前 Tab 顺序为：代码片段下一个位置 → 补全菜单下一个候选 → 尝试跳出括号 / 引号 → 普通 Tab 行为。`Shift+Tab` 反向操作。菜单和片段优先，所以 Tab 不会始终插入缩进。

| 输入模式中的按键 | 补全菜单操作 |
| --- | --- |
| `Ctrl+Space` | 手动显示补全；菜单显示时切换文档显示 |
| 上下方向键 / `Ctrl+p / Ctrl+n` | 选择上一项 / 下一项 |
| Enter | 接受已选候选；没有可接受候选时回到普通换行行为 |
| `Ctrl+y` | 选择并接受候选 |
| `Ctrl+e` | 取消补全菜单 |
| `Ctrl+b / Ctrl+f` | 滚动补全文档，菜单文档可用时生效 |

练习：输入类名或方法名前缀 → 用下方向键选候选 → Enter 接受 → 片段有占位符时用 Tab 跳到下一项。`Ctrl+p` 在普通模式是文件搜索，在输入模式是补全选择，两者由模式区分。

### 13.2 跳转定义和查看引用

1. 光标放在类、方法或变量上。
2. F12 跳转到定义。
3. Shift+F12 查看引用列表。
4. Enter 打开某个引用结果。
5. `Alt+←` 返回原位置。

找不到定义可能是语言服务未启动、依赖未解析或该语言不支持相应能力。用 `:checkhealth vim.lsp` 检查。

### 13.3 查看类型和说明

光标放在符号上按 `K` 查看悬浮信息。内容取决于语言服务提供的数据，可能包括类型、签名和文档。Esc 可关闭提示或返回编辑。

### 13.4 重命名符号

1. 光标放到要重命名的符号上。
2. 按 F2 或 `空格 c r`。
3. 输入新名称，观察修改预览。
4. Enter 执行，Esc 取消。
5. 检查受影响文件，再正常保存。

重命名可能影响多个文件。语言服务器不支持或未就绪时，不能保证自动完成。

### 13.5 查看错误并修复

- 状态栏显示错误和警告数量。
- `空格 x x` 打开诊断列表。
- 在列表中选择条目，Enter 跳转。
- 光标放在问题处，`空格 c a` 查看可用代码操作。
- 需要格式化时使用 `空格 c f`。

代码操作可能修改代码，执行前读清选项。格式化失败时先检查对应格式化工具，而不是反复调用快捷键。

## 14. 构建、运行、测试与调试

本节说明操作顺序。JDK、Rust、Kotlin 和 Signal-Server 的环境设置见 [开发环境配置](development.md)。

### 14.1 运行项目任务

1. 确认当前项目，必要时输入 `:pwd`。
2. 普通模式按 `空格 r r`。
3. 在任务列表选择编译、构建、测试或运行。
4. 查看任务状态和输出。

任务会识别 Cargo、Maven、Gradle、package.json 等项目。启动前会保存文件，因此不要在仍打算放弃修改时直接运行任务。

### 14.2 管理任务

| 任务 | 快捷键 / 命令 |
| --- | --- |
| 运行任务 | `空格 r r` / `:ProjectRun` |
| 重新运行上次任务 | `空格 r l` / `:ProjectRerun` |
| 停止运行中的项目任务 | `空格 r s` / `:ProjectStop` |
| 打开任务列表 | `空格 r o` / `:OverseerOpen` |
| 打开编译错误列表 | `空格 r e` |
| 下一条 / 上一条错误 | `:cnext` / `:cprev` |
| 关闭错误列表 | `:cclose` |

查看任务输出时先选中对应任务，操作键以任务面板提示为准。失败时先读完整输出，再判断是编译错误、缺失命令还是项目依赖问题。

### 14.3 测试入口

- `空格 r t`：当前测试 / 选择测试。
- `空格 r T`：当前测试类 / 文件级测试。
- `空格 r f`：重新运行失败的测试任务。

Java 依赖 JDTLS 测试支持；Rust 打开语言服务的测试列表；Kotlin Gradle 项目会询问测试类或方法筛选器。失败重跑是重新运行整个失败任务，不保证只运行失败的测试用例。

### 14.4 调试的基本顺序

1. 先确保项目能正常构建和运行。
2. 打开要调试的源码，等待语言服务。
3. 按 F9 添加 / 移除断点。
4. 按 F5 选择配置并启动，或附加到已有进程。
5. 命中断点后查看调试窗口中的调用栈和变量。
6. 再次 F5 继续。
7. `空格 d t` 结束当前调试会话。

断点命中后，可使用以下调试控制：

| 操作 | 快捷键 |
| --- | --- |
| 单步进入被调用的方法 | `空格 d i` |
| 单步跳过当前语句中的调用 | `空格 d O`，最后是大写 O |
| 从当前方法执行到返回处 | `空格 d o` |
| 继续运行 | F5 / `空格 d c` |
| 运行到当前光标位置 | `空格 d C`，最后是大写 C |
| 设置条件断点 | `空格 d B` |
| 暂停 | `空格 d P` |
| 查看当前符号的调试值 | `空格 d w` |
| 打开 / 收起调试 REPL | `空格 d r` |
| 结束调试 | `空格 d t` |

单步功能需要调试会话已经启动。比如“F9 → F5 → 命中断点 → 空格 d O → F5”就是设置断点、启动、单步跳过、继续的完整流程。

调试器与运行任务不是同一功能。普通运行成功不意味着调试配置已经完整；结束调试是否结束应用进程，取决于使用 launch 还是 attach 和具体适配器。

### 14.5 Signal-Server 日常流程

首次执行 `:SignalSetup`，配置 JDK、YAML 和 secrets 文件路径。

1. `空格 r r` 选择编译或打包。
2. 需要验证时运行 UtilTest 或相应测试任务。
3. 运行服务前确保数据库及外部依赖可用。
4. 普通运行：选择运行服务任务。
5. 调试：选择监听调试端口的启动任务，在 Java 文件 F9 设置断点，再按 `空格 r d` 附加。

当前预设默认附加 `127.0.0.1:5005`。这是 Signal-Server 的专用流程，不适用于所有 Java 项目。

## 15. Git 与修改对比

### 15.1 打开 LazyGit

1. 进入 Git 项目。
2. 普通模式按 `空格 g g`。
3. 在 LazyGit 中使用其自身的导航与操作。
4. `?` 查看当前界面的快捷键帮助。

如果打不开，执行 `:DevHealth` 检查 `lazygit`，并确认当前目录属于 Git 仓库。

### 15.2 查看未提交修改

1. 在文件面板选择修改过的文件。
2. 查看差异面板中的新增、删除和修改。
3. Enter 进一步进入文件 / 修改块视图。
4. `q` 返回上一层；回到顶层后再次 `q` 退出 LazyGit。

这里只查看差异不会自动提交。暂存、提交、丢弃、推送等操作，以面板提示和帮助为准，确认对象后再执行。

### 15.3 提交前建议检查

1. 在 Neovim 保存需要提交的源码。
2. 运行相应构建或测试。
3. 打开 LazyGit 检查文件和 Diff。
4. 只暂存需要提交的内容。
5. 输入提交说明并提交。
6. 是否推送到远端，由你根据项目流程决定。

Git 查看的是磁盘与仓库状态。缓冲区中尚未保存的修改，可能还不会出现在预期的 Git Diff 中。

## 16. Markdown 编辑与预览

打开 Markdown 文件，默认左侧源码、右侧 Markview 只读预览。编辑源码后，预览会更新；正文滚动也会同步。

| 需求 | 操作 |
| --- | --- |
| 聚焦源码 / 预览 | 鼠标点击，或 `Ctrl+h/l` |
| 关闭终端内预览 | `:MarkdownSplitClose` |
| 重新打开终端内预览 | `:MarkdownSplit` |
| 手动启动浏览器预览 | `:MarkdownPreview` |

右侧预览不是另一个需要保存的文件。请在左侧编辑，保存时保存源 Markdown 文件。

终端预览适合标题、列表、代码块和表格等。复杂 HTML、CSS、网页排版、SVG 和图片不保证与浏览器一致。需要网页完整渲染时，手动使用浏览器预览，并先确认其插件前端依赖已安装。

## 17. 主题、缩略图与光标动画

### 17.1 项目主题

1. 进入目标项目。
2. 按 `空格 u P`。
3. 输入主题名称筛选。
4. 移动选择时实时预览。
5. Enter 确认并保存给当前项目。
6. Esc 取消，恢复之前设定。

`:ProjectThemeReset` 清除当前项目专属主题。主题记录在 Neovim 状态目录，不修改项目文件；其他项目可以使用不同主题。

### 17.2 代码缩略图

- `空格 u m`：全局显示 / 隐藏。
- `空格 u M`：切换缩略图焦点。
- 点击缩略图：定位代码。
- `:Neominimap Refresh`：手动刷新。

缩略图默认位于代码区右侧。窗口宽度至少 100 列、文件少于 20000 行时才显示。终端、文件树、预览和装饰栏会跳过。图形通过 Braille 字符绘制，字体不支持时会出现方框或不完整字符。

### 17.3 平滑光标

`空格 u A` 临时开关。当前使用 smear-cursor.nvim 的快速、无拖尾方案，插入模式、跨窗口和辅助区域不播放动画。

不同终端与字体的实际观感有差异。感觉延迟或拖影时直接关闭；要永久关闭，在 `lua/plugins/cursor-animation.lua` 中对 smear-cursor.nvim 设置 `enabled = false` 后重启。

## 18. 位置标记、文件管理与数据库

### 18.1 位置标记

| 操作 | 快捷键 |
| --- | --- |
| 在当前行添加位置标记 | `空格 m a` |
| 删除当前行标记 | `空格 m d` |
| 下一个 / 上一个标记 | `空格 m n` / `空格 m p` |
| 查看标记列表 | `空格 m l` |

适合临时记住多个正在比较的方法或代码位置。位置标记不等于调试断点，断点用 F9。

### 18.2 Oil 文件管理

按 `空格 f o` 打开浮动文件管理器。它将目录内容当成可编辑列表，适合批量改名等操作。

常见改名流程：

1. 进入目标目录。
2. 找到对应文件行。
3. 编辑该行中的文件名。
4. 执行 `:w`。
5. 查看操作确认内容，再确认执行。

这类操作会改变真实磁盘文件。删除列表中的条目也可能表示删除文件，不是单纯从搜索结果隐藏。没有把握时，使用 Windows 文件资源管理器。

### 18.3 数据库面板

- `空格 D`：切换数据库面板。
- `:DBUI`：打开数据库面板。
- `:DBUIAddConnection`：按插件提示添加连接。

还需安装对应数据库客户端，例如 PostgreSQL 的 psql、MySQL 客户端或 sqlite3，并自行提供连接。数据库并不会随着 Neovim 配置自动安装。

SQL 缓冲区可以获得数据库补全，但能否连接与执行取决于驱动、客户端、网络和账户权限。先确认当前连接指向开发环境，再运行修改数据的语句。

## 19. 保存、退出与异常恢复

### 19.1 保存文件

| 需求 | 命令 / 按键 |
| --- | --- |
| 保存当前文件 | `Ctrl+s` / `:write` / `:w` |
| 保存所有已修改文件 | `:wall` |
| 未命名文件指定保存路径 | `:write C:/My/code/demo/new-file.txt` |
| 保存工作区记录 | `空格 q S` / `:WorkspaceSave` |

保存文件与保存工作区是两个不同操作。普通切换文件、窗口和项目不会自动写入全部源码；运行项目任务前会触发保存。

### 19.2 推荐退出方式

输入 `:Exit`：

- 保存所有文件并退出。
- 不保存所有文件并退出。
- Esc 取消。

只关闭文件用 `空格 b d`。`:q` 关闭当前窗口；`:qa` 请求关闭全部窗口，存在未保存修改时会受保护；`:qa!` 放弃修改并退出，应明确确认不需要改动后使用。

### 19.3 操作错了怎么办

| 情况 | 首先尝试 |
| --- | --- |
| 刚删错内容 | Esc，再按 `u` |
| 不知道现在是什么模式 | 看状态栏，按 Esc；终端使用 `Ctrl+\` 再 `Ctrl+n` |
| 终端不见了 | F7；不等于进程已结束 |
| 跳转后找不到原位置 | 编辑区 `Alt+←` 或 `Ctrl+o` |
| 主题预览不喜欢 | 尚未确认时按 Esc |
| 误关了文件 | `Ctrl+p` 再打开；未保存内容是否仍在取决于关闭时选择 |
| 需要原来的布局 | `空格 q s` 恢复已保存工作区 |

### 19.4 配置备份

- `:ConfigBackup`：备份当前配置。
- `:ConfigRestore`：选择备份回退，恢复前会再次备份。
- 回退后重启 Neovim，按需执行 `:Lazy restore`。

配置备份不包含业务源文件、未保存缓冲区、全部插件安装目录和 Mason 工具，不能用它代替项目的 Git 或文件备份。

### 19.5 检查环境

- `:DevHealth`：本配置的开发命令与 LSP 检查。
- `:checkhealth`：Neovim 和插件的详细健康检查。
- `:Lazy`：插件安装与更新状态。
- `:Mason`：语言工具状态。
- `:LspLog`：语言服务日志。

更多处理步骤见 [故障排查](troubleshooting.md)。

## 20. 典型工作流程与快捷键速查

### 20.1 查找某个方法并修改

`Ctrl+p` 找文件 → `/方法名` 定位 → F12 跳转定义 → 修改 → Esc → Ctrl+s → `Alt+←` 返回。

若已经知道项目中的关键词但不知道文件名，直接使用 `空格 /`。

### 20.2 修改后测试并检查 Diff

保存文件 → `空格 r r` 选择测试 → `空格 r o` 查看输出 → 必要时 `空格 r e` 定位错误 → `空格 g g` 查看 Git Diff。

### 20.3 服务持续运行时继续编辑

`空格 t` 新建终端 → 启动服务 → `Ctrl+k` 回代码 → 编辑和保存 → F7 显示日志 → 点击其他终端标签执行临时命令。

### 20.4 换项目但保留当前进度

保存需要保留的文件 → `空格 q S` 保存当前布局 → `空格 f p` 选择另一个项目。下次从项目列表返回，会复用当前进程的工作区或恢复已保存记录。
